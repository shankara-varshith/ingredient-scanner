Live dashboard preview — how fields render
typical_in_product actual value shown in the amounts label and fills the bar
safe_upper_limit the vertical marker line on the gauge bar
tolerable_upper_limit the right edge (100%) of the bar scale
pct drives bar fill width: 50 = halfway to safe limit
exceeds_safe turns the amounts label red when true
severity_level green / amber / red bar colour

pct calculation rules:
Risks: pct = (actual ÷ safe) × 100   |   Benefit: pct = min((actual ÷ rda) × 100, 100)
Bar fill width = min(pct ÷ 2, 100)%   so 200% pct = full bar (exceeds limit by 2×)
